# Instructions du projet

**Statut : Brouillon** — **Dernière mise à jour : 2026-09-26**

- Application Windows locale, sans service ni télémétrie.
- Tout verrouillage clavier doit rester temporaire et offrir une voie de déverrouillage par souris.
- Ne pas ajouter de dépendance tierce sans nécessité documentée.
- Préserver le fonctionnement sans élévation et signaler les limites du hook dans la documentation.
- Compiler avec la commande du README pour vérifier une livraison. Ne pas prétendre qu’un build a été vérifié s’il n’a pas été exécuté.
