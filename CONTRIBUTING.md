# Contribution

**Statut : Brouillon** — **Dernière mise à jour : 2026-09-26**

## Prérequis

- Windows 10 ou 11 et SDK .NET 8 pour compiler.
- Aucun paquet NuGet tiers n’est requis.

## Workflow

**Mainteneur :** Bougli. Les contributions externes sont acceptées via GitHub ; les modalités exactes de soumission restent à définir.

Pour proposer une contribution, décrire le problème ou le besoin, résumer les changements et leurs effets sur le verrouillage ou le déverrouillage. Garder le filtre de clavier limité à la durée demandée, toujours permettre le déverrouillage souris et préserver les changements hors périmètre. Documenter les changements qui touchent aux hooks, au délai de sécurité ou à la zone de notification. Compiler avec la commande de publication indiquée dans le README avant toute livraison.
