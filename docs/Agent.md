# Rôle des agents

**Statut : Brouillon** — **Dernière mise à jour : 2026-09-26**

Les assistants peuvent contribuer à la conception, au code et à la documentation. Ils doivent préserver le déverrouillage souris et le délai de sécurité, distinguer les contrôles exécutés des contrôles seulement documentés, et ne pas lancer de tests actifs contre une cible externe.
