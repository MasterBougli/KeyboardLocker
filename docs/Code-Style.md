# Style de code

**Statut : Brouillon** — **Dernière mise à jour : 2026-09-26**

- C# nullable activé, types et méthodes en PascalCase, champs privés en `_camelCase`.
- Une responsabilité par composant ; commentaires XML pour les composants natifs sensibles.
- API Win32 isolées dans `KeyboardHook.cs` et libération déterministe des ressources.
