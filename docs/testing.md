# Vérifications

**Statut : Brouillon** — **Dernière mise à jour : 2026-09-26**

## Vérification de compilation

Exécuter la commande `dotnet publish` indiquée dans le README depuis Windows avec le SDK .NET 8.

## Vérifications manuelles avant livraison

1. Confirmer que le clavier est bloqué après activation et que la souris reste fonctionnelle.
2. Déverrouiller depuis le bouton puis depuis le menu de l’icône de notification.
3. Vérifier l’échéance sur une courte durée et vérifier que la fermeture libère le hook.
4. Confirmer que les touches Windows et Ctrl+Alt+Suppr gardent le comportement système documenté.
5. Vérifier qu’Alt+F4 est bloqué par défaut, puis autorisé quand la case est cochée.

Aucune de ces vérifications n’est déclarée exécutée par la seule présence de cette procédure.
